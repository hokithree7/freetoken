# Security policy

Do not open a public issue containing API keys, authentication tokens, private account data, Vault material, or a reproducible exploit against the live service.

For a sensitive vulnerability, use GitHub's private vulnerability reporting flow for this repository:

`https://github.com/hokithree7/freetoken-link/security/advisories/new`

Private vulnerability reporting must be enabled before this repository is announced publicly. If the private form is unavailable, do not place sensitive details in a public issue; the repository owner must first restore a private reporting channel.

For non-sensitive documentation and source corrections, use the public issue templates.

The public repository intentionally excludes production source code and secrets. Its presence does not change the live product's browser-direct credential and client-encryption boundaries.
