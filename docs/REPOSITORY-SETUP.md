# Repository publication checklist

Complete these settings before announcing the repository.

## Required

- Create the repository as **public** under `hokithree7/freetoken-link`.
- Keep `https://freetoken.link/` as the website and product canonical.
- Keep GitHub Pages disabled; this repository is documentation, not a duplicate website.
- Enable GitHub **Private vulnerability reporting** and test that the private report link in `SECURITY.md` opens.
- Create the labels `source-correction` and `provider-suggestion` so the Issue Forms can attach them.
- Confirm that the default branch is `main` and that accidental force-pushes and branch deletion are blocked.

## Repository profile

- Description: `Find and verify free-access LLM API routes: dated official conditions, supported browser-direct checks, key-free configuration templates, and a change-focused Watchlist.`
- Website: `https://freetoken.link/`
- Topics: `llm`, `free-api`, `developer-tools`, `api-keys`, `openai-compatible`, `ai-tools`, `model-monitoring`

## Read-back after push

- Open every language switcher link from the rendered README.
- Open both Issue Forms and confirm their labels appear.
- Open the private vulnerability reporting form while signed in.
- Confirm the overview image renders at desktop and mobile widths.
- Confirm the repository contains no production source, environment files, credentials, Vault records, or user data.
