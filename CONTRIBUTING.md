# Contributing evidence and corrections

FreeToken.link welcomes corrections, provider suggestions, reproducible compatibility notes, and documentation improvements.

## Good contributions

- A provider-owned documentation, pricing, quota, status, or model-catalog URL.
- The exact provider and API model ID affected.
- The access condition that changed: card, phone, region, quota, key flow, or model availability.
- The date and timezone of the observation.
- A minimal, redacted reproduction that does not disclose credentials or personal data.

## Evidence rules

1. Provider-owned sources are publication evidence.
2. Community directories, social posts, and forum discussions are discovery leads only.
3. A single failed request does not prove a provider-wide outage.
4. Account-specific quota, region, and eligibility must be labeled as such.
5. Never claim “free forever,” universal availability, or guaranteed compatibility.

## Never submit

- API keys, bearer tokens, cookies, passwords, private endpoints, or `.env` contents.
- User Vault ciphertext or recovery material.
- Screenshots containing email addresses, billing details, project IDs, or other personal data.
- Scraped or shared credentials.
- Promotional backlinks unrelated to a verifiable correction.

Use the issue templates so a correction can be reviewed without guessing its source or scope.
